About CampusFix

Understanding the problem, the solution, and the road ahead.

ℹ️ About CampusFix

CampusFix is a Smart Campus Maintenance & Complaint Management System built as an individual Web Technology Lab project. It provides a centralized platform where students and staff can report maintenance issues — such as broken lights, water leakage, damaged furniture, network problems, and laboratory equipment failures — and track them from submission to resolution.

The application is built entirely with HTML5, CSS3, and Vanilla JavaScript, with no frontend frameworks and no backend server. All data is stored in the browser using localStorage.

⚠️ Problem Statement

In colleges, students and staff frequently face maintenance problems including broken lights, faulty fans, water leakage, damaged furniture, Wi-Fi/network issues, laboratory equipment failures, classroom problems, cleanliness issues, and electrical faults.

Currently, these issues are often reported verbally or through messaging applications. This makes it difficult to:

  • Track which complaints have been submitted
  • Identify the priority of each issue
  • Monitor whether an issue has been resolved
  • Maintain a record of recurring problems
  • Assign responsibility and ensure accountability

💡 Proposed Solution

CampusFix provides a centralized web application where students and staff can submit maintenance complaints through a structured form and track their status through a visual dashboard and status timeline.

  • A complaint form captures all necessary details (name, department, location, category, priority, description, date)
  • Each complaint receives a unique ID (CF001, CF002, CF003, …) for easy reference
  • A dashboard displays live statistics and a searchable, filterable, sortable table of all complaints
  • A details page shows full complaint information and a visual status timeline from Reported to Resolved
  • All data persists in the browser using localStorage — no server or login required

🎯 Objectives

  • Provide a simple, centralized platform for reporting campus maintenance issues
  • Replace untracked verbal/messaging-based reporting with a structured system
  • Generate unique complaint IDs for easy tracking and referencing
  • Display real-time statistics on complaint status and priority levels
  • Enable searching, filtering, and sorting of complaints on a dashboard
  • Show a visual status timeline from submission to resolution
  • Demonstrate practical use of HTML5, CSS3, and JavaScript (DOM, events, localStorage, JSON)

✅ Benefits

  • Faster response times — maintenance teams can prioritize critical issues
  • Centralized tracking — no complaints get lost or forgotten
  • Prioritized resolution — critical issues are immediately flagged
  • Data-driven insights — statistics reveal recurring campus problems
  • Transparency — students and staff can track complaint progress
  • Accountability — every complaint has a unique ID and a status record

🚀 Future Enhancements

This is a client-side prototype. Future versions of CampusFix can be extended with the following:

  • PHP backend or Servlet backend for server-side processing
  • MySQL database for permanent complaint storage
  • Admin login for maintenance staff to manage complaints
  • Technician assignment to route complaints to the right personnel
  • Email notifications when complaint status changes
  • Real-time complaint tracking with live updates
  • Analytics dashboard with charts and trend analysis
  • Role-based access (students, staff, admins, technicians)
  • Full CRUD operations (create, read, update, delete complaints)
